# Сборка YALS Server (ARM)

## Сборка

Для сборки проекта выполните скрипт `build.sh` из папки исходников:  
```bash
chmod +x build.sh
./build.sh
```

## Пересборка с нуля

Чтобы полностью очистить папку сборки и собрать проект заново, используйте флаг `--rebuild`:  

```bash
./build.sh --rebuild
```

Сборка появится в каталоге `../../../build/yav/server`.
